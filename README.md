## 👋 About

현재 [MHNCity](https://github.com/MHNCity)에서  
컴퓨터 비전 기반 영상 분석·관제 서비스의 **Backend / Infrastructure**를 담당하고 있습니다.

영상 입력부터 AI 추론, 이벤트 처리, 저장과 알림까지 이어지는 흐름을 다루며  
**성능 병목, 상태 불일치, 장애 복구와 운영 안정성**을 주로 개선하고 있습니다.

문제가 생기면 같은 상황을 먼저 만들어 보고  
로그·메트릭·네트워크·DB·Queue·Storage를 따라가며 원인을 좁힙니다.

`재현 → 원인 확인 → 수정 → 배포 → 검증`

그리고 특정 분야 안에서만 기술을 사용하는 것보다  
**다른 분야에서 문제를 발견하고, 필요한 기술을 가져와 해결하는 과정**을 좋아합니다.

경영학, 컴퓨터공학, 중어중문학처럼 서로 다른 분야를 경험하면서  
새로운 것을 접할 때마다 자연스럽게 이런 생각을 합니다.

> **“이걸 기술로 조금 더 편하게 만들 수 없을까?”**

---

## 🎯 What I Want to Solve

여러 경험을 하면서 기술의 가치는  
기술 자체가 복잡하고 대단한 데 있는 게 아니라는 생각을 하게 됐습니다.

누군가 반복해서 불편해하는 일을 줄여주거나,  
어렵던 일을 쉽게 만들고, 시간을 아껴줄 수 있을 때  
기술이 가장 의미 있다고 생각합니다.

그래서 앞으로는 특정 산업이나 기술에 한정되기보다  
**사람들이 일상이나 업무에서 당연하게 감수하고 있는 불편을 찾아 해결하고 싶습니다.**

> **기술을 쓴 티가 나는 서비스보다,  
> 써보니 편한 서비스를 만들고 싶습니다.**

제가 만든 것을 실제 사람이 사용하고  
그전보다 조금이라도 편해졌다고 느끼게 만드는 것이  
앞으로도 계속 해결하고 싶은 문제입니다.

## ⚙️ Engineering Focus

### AI Systems

영상 분석 모델을 실제 서비스에서 운영하기 위한  
**Serving · Event Pipeline · Async Processing**을 다룹니다.

모델 호출 자체보다 처리 병목, 이벤트 지연·유실,
중복 처리와 서비스 재시작 이후의 상태까지 함께 봅니다.

`Triton Inference Server` `Ray` `YOLO` `VLM` `FFmpeg`

### Backend & Reliability

API부터 DB, Queue, Cache, WebSocket, Object Storage까지  
여러 시스템을 거치는 데이터 흐름을 개발하고 운영합니다.

특히 **지연 · 유실 · 중복 처리 · 상태 불일치** 문제에 관심이 많습니다.

`Node.js` `Express` `FastAPI` `RabbitMQ` `Redis` `Socket.IO`

### Infrastructure & Security

Kubernetes 기반의 배포·모니터링·장애 복구 환경을 관리하고,  
인증·권한·세션·입력값·파일 처리 보안도 함께 다룹니다.

장애를 막는 것만큼  
**문제를 빠르게 발견하고 다시 정상 상태로 돌리는 과정**을 중요하게 생각합니다.

`Kubernetes` `Terraform` `GitOps` `Prometheus` `Grafana`
